# Refract

A desktop Twitch app for Windows: watch up to 4 streams at once, Chatterino-style chat with BTTV, FFZ and 7TV emotes, Moments, achievements and more.

## Download

**Get Refract only from this page:** [Latest release](https://github.com/ShadowHexYT/Refract-releases/releases/latest)

1. Download `Refract_X.Y.Z_x64-setup.exe` (or the `.msi`).
2. Run it. Windows may say "Windows protected your PC". Click **More info → Run anyway** (the app isn't code-signed yet).
3. After that, Refract updates itself. You never need to download it again.

## Stay safe

- **This is the only official place to download Refract.** It is free. Nobody should ever charge you for it.
- Don't run Refract from Discord DMs, file-sharing sites, YouTube links or "cracked/premium" versions. Those are not from us.
- Refract never asks for your Twitch password. You sign in on Twitch's own website.
- To be sure your download is the real one, check its SHA-256 fingerprint against the one listed on the release:
  open PowerShell in your Downloads folder and run `Get-FileHash .\Refract_X.Y.Z_x64-setup.exe`.
- Updates from inside the app are signed. Refract refuses to install an update that wasn't signed by us.
